WHAT IS SUPERCYCL

수퍼사이클이란?

고야차트와 연동되어 시그널 확인 → 거래 실행까지 한 번에 끝내는 시그널 매매 특화 플랫폼

📡

실시간 시그널 알람

고야차트의 유스메타(YouthMeta) 매매 시그널을 ▲Long / ▼Short로 즉시 확인하고, confirmed / unconfirmed 상태까지 제공합니다.

🔁

시그널 → 거래 원클릭

차트를 보다가 바로 Trade Now 버튼을 눌러 거래소로 이동, 시그널 분석 결과에 맞춰 주문까지 한 흐름으로 실행합니다.

🔔

반대 방향 경고

현재 보유 중인 포지션이 시그널 방향과 다르면 경고 표시가 떠서, 불필요한 역방향 손실을 미리 막아줍니다.

🎁

신규 회원 혜택

연동 후 거래만 해도 USDT · ICX 지급 이벤트가 준비되어 있습니다. 아래 이벤트 섹션에서 확인하세요.

✅ 전 기능 이용

기존 Goya 알람 패키지 이용 회원

수퍼사이클의 모든 알람 기능을 제한 없이 사용할 수 있습니다. Long / Short 시그널과 반대 방향 경고가 모두 제공됩니다.

⚠️ 일부 제한

차트만 구독 · 알람 패키지 없는 경우

이 경우 반대 시그널 알람만 제공됩니다. 빠짐없는 시그널 이용을 원한다면 알람 패키지 구독을 권장합니다.

🚨 필수 연동 수칙 — 이걸 놓치면 모든 기능이 작동하지 않습니다

수퍼사이클은 반드시 EX 로그인 후 고야차트에 접속하여,
리스트 상단의 【Trade Now】 버튼을 클릭하여 연동해야 정상 작동합니다.

STEP BY STEP

첫 접속부터 매매까지 5단계

아래 순서대로 따라하면 약 10분이면 세팅이 끝납니다

STEP 01

모바일 접속 & 로그인

수퍼사이클 앱은 모바일 웹에서 바로 사용할 수 있습니다.

  • 1
    모바일 브라우저에서 접속주소창에 mapp.supercycl.io 입력 후 접속
  • 2
    계정으로 로그인Continue with email (이메일) 또는 Continue with Google (구글 계정) 선택
  • 3
    로그인 완료 확인하단 탭바에 Signals · Trade 메뉴가 보이면 성공
💡 TIP  iPhone 사용자는 나중에 푸시 알림을 받으려면 반드시 홈 화면에 추가(PWA)로 실행해야 합니다. 일반 웹 브라우저에서는 알림이 수신되지 않습니다.
STEP 02

OKX 거래소 연동

시그널을 실제 매매로 잇는 가장 중요한 연결 작업입니다.

  • 1
    거래소 연결 메뉴 진입화면의 Connect Your Exchange 메뉴에서 Connect Now 터치
  • 2
    OKX 계정 로그인보유 중인 OKX 계정 정보로 로그인
  • 3
    Fast API 권한 승인Third-party authorization (PortX) 화면에서 Confirm / Authorize 터치하여 승인 완료
  • 4
    EX → Trade Now 연동 필수!EX 로그인 후 고야차트 접속 → 리스트 상단 Trade Now 클릭으로 연동해야 정상 작동

⚠️ 자주 발생하는 오류: Fast API 중복

OKX는 Fast API 키를 1개만 발급할 수 있어서, 이전에 발급한 키가 남아 있으면 위 오류가 발생합니다. 아래 순서로 해결하세요.
  1. PC 또는 모바일 브라우저로 okx.com 웹사이트에 직접 접속
  2. OKX 계정 로그인
  3. Third-party authorization (PortX) 설정으로 이동
  4. 기존에 발급된 API 키를 Remove (삭제)
  5. 수퍼사이클 앱으로 돌아와 연동을 다시 시도 → 정상 해결
STEP 03

실시간 시그널 알람 설정

시그널을 놓치지 않도록 알람을 켜고, 이용 중인 플랜에 맞춰 설정합니다.

  • 1
    Signals 탭 확인앱 하단 Signals 탭을 누르면 유스메타 매매 시그널 ▲Long / ▼Short와 현재 상태(confirmed / unconfirmed)를 확인할 수 있습니다
  • 2
    플랜 선택이용 중인 상품에 맞춰 Premium 또는 Smart 탭을 선택하여 차트 조회
  • 3
    반대 방향 경고 확인보유 중인 포지션이나 주문이 시그널 방향과 다를 경우 경고 표시가 나타납니다 → 즉시 재확인
  • 4
    푸시 알림 활성화Profile → Notifications에서 알림 켜기 (iPhone은 홈 화면에 추가한 PWA 앱 상태에서만 수신)

STEP 04

신규 코인 종목 등록

매매하고 싶은 종목을 등록해두면 이후 관리가 훨씬 편해집니다.

  • ①
    고야 알람 확인고야차트에서 관심 종목의 시그널이 발생했는지 확인
  • ②
    EX 사이트로 이동Trade Now 버튼을 통해 EX 거래소 사이트로 이동
  • ③
    신규 종목 선택 & 등록·저장원하는 신규 종목을 선택한 뒤 등록 및 저장을 완료하면 끝!
💡 TIP  등록해둔 종목은 시그널 알람과 매매 화면에서 바로바로 불러올 수 있어, 매번 검색할 필요가 없습니다.
STEP 05

실전 매매(TRADE) 주문

마지막 단계! 시그널을 보고 조건을 설정한 뒤 주문을 실행합니다.

  • 1
    Trade 탭 이동앱 하단의 Trade 탭 터치
  • 2
    거래 종목 선택상단에서 거래할 코인 선택 (예: BTC/USDT)
  • 3
    주문 조건 설정주문 방식(Market / Limit) · 증거금 모드(Isolated 등) · 레버리지(2x 등) · 포지션 모드(Hedge 등) 설정
  • 4
    거래 금액 입력수량 및 금액(Amount) 입력 — 초보자는 소액부터!
  • 5
    주문 실행시그널 분석 결과에 맞게 [Long] 또는 [Short] 버튼을 눌러 최종 거래 체결
⚠️ 주의  시그널은 참고 자료이며, 레버리지 거래는 손실 위험이 따릅니다. 반드시 본인이 감당 가능한 금액으로, 증거금 모드와 레버리지를 설정한 뒤 거래하세요.

FAQ

자주 묻는 질문

사용은 가능하지만 반대 시그널 알람만 제공됩니다. 유스메타의 ▲Long / ▼Short 전체 시그널을 이용하려면 기존 Goya 알람 패키지 구독이 필요합니다.
대부분 EX 로그인 → 고야차트 접속 → 리스트 상단의 Trade Now 버튼 클릭 순서를 거치지 않아서 발생합니다. 반드시 위 순서로 연동해야 정상 작동합니다.
OKX는 Fast API 키를 1개만 발급할 수 있습니다. okx.com 접속 → 로그인 → Third-party authorization (PortX) → 기존 키 Remove 후 앱에서 다시 연동하면 해결됩니다.
iPhone은 웹 브라우저(사파리)에서 바로 접속한 상태로는 푸시 알림이 수신되지 않습니다. 브라우저 메뉴에서 홈 화면에 추가를 선택해 PWA 앱으로 실행한 뒤, Profile → Notifications에서 알림을 활성화해야 합니다.
이용 중인 상품(플랜)에 맞춰 선택하면 됩니다. Premium 상품을 구독 중이면 Premium 탭, Smart 상품이면 Smart 탭에서 해당 차트와 시그널을 조회합니다.

이 가이드, 초보 회원에게 공유하세요 🔁

주소만 복사해서 카톡방이나 단톡방에 바로 공유할 수 있습니다.
